## Host roles

### G1_RPI_GATEWAY

The Raspberry Pi host is named `mist-5`. It has local IP `192.168.1.126`.

The relevant production path is generated by:

```text
/home/mist/Software/EnvData.py
```

The script publishes sensor measurements to:

```text
177.104.61.23:1883
```

A LoRa packet forwarder also exists, but it points to TTN rather than to the private ChirpStack host.

### C1_CHIRPSTACK_CLOUD

This host has IP:

```text
177.104.61.23
```

It runs:

```text
chirpstack
chirpstack-gateway-bridge
mosquitto
postgres
redis
```

For this capture, its most important role is receiving MQTT messages and acting as the MQTT source for the Python adapter on host `177.104.61.21`.

### C2_MAGISTRALA_ADAPTER

This host has IP:

```text
177.104.61.21
```

It runs the Python adapter:

```text
/usr/bin/python3 /home/ubuntu/adapter/src/main.py
```

The adapter maintains a connection to:

```text
177.104.61.23:1883
```

It then writes the decoded/converted sensor data into Magistrala/SuperMQ using HTTP/SenML.

Magistrala/SuperMQ runs in Docker on network:

```text
absmach_magistrala_magistrala-base-net
bridge: br-2b65035ed9b3
subnet: 172.18.0.0/16
```

Important internal container IPs:

| Container | IP | Role |
